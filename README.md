# Buttercup_AI
Buttercup AI is a personal AI assistant with persistent memory, built using the Qwen3-4B-Instruct language model.

The project focuses on creating an AI assistant that can have natural conversations, remember selected user information, and use web search when current information is needed.

✨ Features
🤖 Qwen3-4B-Instruct based AI assistant
🧠 Persistent user memory
💾 JSON-based memory storage
💬 Context-aware conversations
🔎 Web search using Tavily
👤 Personalized user profile
🗂️ Organized memory categories

🔄 How It Works
User Input
    ↓
Tokenization
    ↓
Memory + Context
    ↓
Qwen3-4B Model
    ↓
Response Generation
    ↓
Final Response

🎯 Goal

The goal of Buttercup is to explore how LLMs, persistent memory, tokenization, and web search can work together to create a more personalized AI assistant.
